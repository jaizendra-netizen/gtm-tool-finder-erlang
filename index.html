gtm_tool_finder_erl

Search the OneGTMLab GTM tool directory from Erlang or your terminal:

  • API reviews for 66 sales and marketing tools: pricing, rate limits, keys and MCP support
  • 99 head-to-head tool comparisons, such as Apollo vs Clay
  • 110 plain-English definitions of GTM terms

Installation

{deps, [gtm_tool_finder_erl]}.

Usage

[io:format("~ts ~ts~n", [N, U]) || #{name := N, url := U} <- gtm_tool_finder_erl:search("enrichment", "Tool", 10)].

Command line: rebar3 escriptize && _build/default/bin/gtm_tool_finder --kind comparison clay.

Every result links to the full page on onegtmlab.dev/tool-directory. The list ships inside the package, so it works offline and sends no data anywhere.

Also available as a Python package, a Ruby gem, an Elixir package and a Gleam package. Built by OneGTMLab, a GTM engineering agency. MIT licensed.
